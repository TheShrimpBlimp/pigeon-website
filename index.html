WHAT IT DOES

From sample to pattern.

01 / CHOP

Find the part you want.

Automatic transient chops with editable boundaries, waveform zoom, pitch, envelopes, hold loops, and latch. Two independent chop layouts share the same audio.

02 / SEQUENCE

Build it on the keys.

A paged step grid with 1–64 steps per track, four patterns, and arrangement sections. Add swing, probability, repeats, pitch locks, and conditional hits.

03 / PERFORM

Play the beat.

Choke groups, held drum rolls, and loop tempo sync. Filter, delay, chorus, reverb, and distortion, with separate compression controls.

UPDATE SAFEGUARDS

Recovery when an update stops.

PIGEON includes installer safeguards and a recovery boot stub adapted from ChoralRoot FM-1 by Quixotic7 and the ChoralRoot contributors. Thank you for making this work open source.

01 / CHECK FIRST

Check the running firmware.

The installer blocks Sloop, old Felucca betas, and unrecognized firmware before starting an update. Follow your current firmware’s procedure to return to official V15 first.

02 / RESUME

Reconnect and finish.

With the recovery stub installed, an interrupted write can return to update mode on power-on. Reconnect the FM1 and run the installer again. Hold OCT- alone while switching on to request recovery mode.

03 / PREPARE

Keep the first install powered.

The first installation of the stub, or a later change to it, has a short unprotected window. Fully charge the FM1, use a direct USB data cable without a hub, keep your computer awake, and leave it connected until the update finishes.

Hardware recovery verification is pending. Host recovery and installer checks passed, and a complete rebuild produced identical firmware hashes. Returning to stock or installing older firmware removes this protection.

Working with drum loops?

Use Song 2 for your break. Set the number of beats in a reference loop, then turn tempo sync on. Playback speed follows project BPM, so pitch changes with tempo.

Sync range: half to double speed. Use a full-loop chop for whole-loop playback, or sequence individual slices.

Full controls and workflow ↗

On SEQ: K1 tempo, K2 tempo/sample-end timing, K3 step, K4 length (1–64). OCT selects step duration. REC arms recording; the screen shows stopped, armed, recording, or playing. Pattern changes wait for the configured next-bar or pattern-end boundary.

BEFORE YOU START

A few practical answers.

Does the sample tool upload my audio to a server?

No. Importing, encoding, previewing, and editing run on your computer in the browser. USB MIDI sends the bank directly to your FM1. Wait for “Offline ready” in the tool before disconnecting the internet; its cached features remain available while browser storage is retained.

Can I return to the original firmware?

Use M-VAVE’s official update procedure with an unmodified official firmware package to return to stock. Returning to stock removes PIGEON’s recovery boot stub. Back up first: the stock firmware cannot open PIGEON projects. A loader-mode recovery needs its own recovery procedure.

Official M-VAVE downloads ↗
Is PIGEON open source?

Yes. PIGEON is free and open-source software licensed under GPL-3.0-only. You can read the code, build it, modify it, and share it under the licence terms. Bug reports and contributions are welcome on GitHub. Each firmware download includes its matching source archive and licensing information.

How is PIGEON related to Felucca?

PIGEON is an independent sampler project built on Felucca. Existing project containers remain supported, but inherited synth tracks do not sound in the sampler profile. New conditional-step data requires current PIGEON firmware.

What has been tested?

This candidate passed PIGEON product checks, sanitizer checks, codec and storage validation, and target CPU-budget checks. All 92 reference audio renders are unchanged. Recovery tests cover 16,143 stub checks and boot decisions after every simulated flash erase/page write; interrupted snapshots resume successfully. This candidate has not been flashed or verified on hardware. USB bank transfers and live playback still need physical testing. Inherited Felucca synth-screen layout checks report font-related failures; the PIGEON screen check reports no fixed-label clipping.
